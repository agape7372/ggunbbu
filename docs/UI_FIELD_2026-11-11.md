# UI 「현장」 구현 (2026-11-11)

사용자 지시(/fobrain): 「건뿌 프론트엔드 ux ui 배치나 가독성 및 디자인 총검토 기존 틀이나 내가 준 규칙에 얽메이지말고 너가 최고의 게임디렉터이자 이 코드의 주인이라고 생각하고 작업 후 시안 먼저 아티팩트로 줘봐」 「시안은 여러개로」

결정 넷(사용자 원문):
1. 「상점은 지금 스타일이 마음에들어」: 상점은 지금 화면 그대로. 아래 단추 줄 순서만 다른 화면과 맞춘다.
2. 「나머진 B가 마음에들어」: 홈 · 작업 지시서 · 판 · 결과는 시안 B(현장)로.
3. 구현 도중 판 캡처의 왼쪽 세로 눈금에 동그라미를 치고 「게이지는 상단에 가로로있으면 좋겠고 최대한 공간차지 덜하게」: 진행 · 보스 게이지는 위 띠 바로 밑 가로 한 줄(높이 13). 시안 B의 왼쪽 세로 눈금은 반려됐다.
4. 2026-11-12 구현본 지도 캡처(390×844)에 빨간 동그라미 셋(1-1 터의 기록 숫자 · 난이도 꼬리표 · 「철거」 도장, 1-2 터의 같은 것, 쪽지 전체와 「착수」)을 치고 「여기 너무 빽빽하다」: 지도 다이어트. 터에는 도장 하나, 접힌 쪽지는 세 줄. 나머지는 지우지 않고 쪽지 펼친 면으로 옮겼다. 해석(두뇌): 승인된 시안 B 지도에는 꼬리표 상자 · 난이도 설명 줄 · 보스 연습 줄이 없었는데 구현이 더 얹었다.

해석: 메뉴 화면을 따로 두지 않는다. 진짜 캔버스와 진짜 조작 키 넷을 메뉴에 그대로 쓴다. 「먹 한 획」 문법(불변 10)은 그대로다.

## §2 구조 계약

### 현장 화면
- 홈과 결과 넷이 현장 화면이다: 진짜 캔버스 위에 투명 화면을 얹는다. 목록 = `FIELD_SCREENS`(`src/ui/overlay.ts:297`).
- 결과 화면 꼬리표(상점 · 미션)만 DOM 단추다. 나머지 동작은 조작 키(`overlay.ts:161` 주석).

### 키 얼굴
- 플레이용 조작 키 넷이 메뉴 단추가 된다. `setFaces(KeyFaces | null)`(`src/input/touch.ts:43` · 구현 `:387`). null이면 플레이 얼굴.
- 얼굴 색조 = `ink | seal | faint | rest`(`touch.ts:12`). 주홍(`seal`)은 공격 키 하나.
- 키 얼굴은 `syncFaces()` 한 곳만 정한다(`src/ui/scenes.ts:227`). 홈이면 `homeFaces`(`src/ui/homeLogic.ts:116`), 결과 카드가 떠 있으면 `resultFaces`, 그 밖은 null. `update()` 머리에서 매 틱 부른다(`scenes.ts:1476`).
- 메뉴 얼굴이 켜져 있는지는 `touch.menu()`(`touch.ts:45`).

### 지도와 「착수」 자리
- 지도 = `mapHtml`(`src/ui/stageView.ts:93`) · 터 = `lotHtml`(`:71`) · 쪽지 = `slipHtml`(`:114`). 건물 글리프 = `src/ui/mapArt.ts`. 모양 = `src/ui/stage.css`.
- 「착수」 자리(11-14 바꿈) = 쪽지 맨 아래 주홍 폭 단추. 옛 공격 키 자리(`goSeat`)는 지웠다. 쪽지는 화면 폭 아래 판이다(DEVLOG 「2026-11-14 (7)」).
- 쪽지를 펼치면 지도는 `inert` + 불투명도 0.22(`stage.css:27`). 0.2 밑으로는 내리지 않는다.
- 지도에서 주홍은 「착수」 하나. 깬 판 도장은 먹이다.
- 난이도 단추는 세 상태(고른 것 · 고를 수 있는 것 · 잠긴 것)를 구분한다. 줄 바꿈은 「·」에서만.

지도 다이어트(11-12, 결정 4). 터와 접힌 쪽지에 정보를 다시 얹지 않는다:
- 깬 터 = 잔해 + 먹 도장 하나(`.mp-cut`, `stageView.ts:85`). 도장 글은 가장 높게 깬 난이도 이름(견습 · 정규 · 외주). 터 위 기록 숫자(`.mp-rec`)와 난이도 꼬리표(`.done .st-lamp`)는 없다. 기록은 쪽지 「내 기록」에만 나온다. 읽어 주는 글(aria-label)의 「철거 정규, 기록」은 그대로다(`stageView.ts:80`~`83`).
- 접힌 쪽지 = 세 줄: 머리 · 기한/전임자/내 기록 · 난이도 셋.
- 펼친 면(`.mp-more-in`) 맨 아래 = 난이도 글(`.mp-note`, `stageView.ts:128`~`130`) + 「보스 연습」 줄(`.mp-prac`, `:131`~`133`). 난이도 글은 세 줄 고정: 「견습 · 기록 안 남음」 「정규 · 기록 남음」 「외주 · 안전모 없음」. 잠긴 난이도는 「외주 · 정규를 깨면 열린다」. 잠긴 판은 「앞 지시서를 끝내면 열린다」 한 줄이고 이것도 펼친 면에 있다(문구 = `src/content/stages.ts:14` · `:15` · `:24`).

브라우저 재현(390×844. 웹은 광고가 없어 일어나기가 바로 된다):
- 창 바깥을 80ms 간격으로 두 번 누름: 고치기 전 = 판으로 넘어감. 고친 뒤 = gameover 그대로.
- 죽는 순간부터 공격 키를 400ms 간격으로 4초 침: 고치기 전 = 일어남. 고친 뒤 = 안 일어나고 키가 옅다. 키가 켜진 뒤 한 번 누르면 일어난다.

안 고친 것: 홈(state 없음)에서 `draw()`가 불투명 메뉴 화면 뒤에서도 매 프레임 홈 그림을 그린다. `src/main.ts`가 틱이 돈 프레임에만 `draw()`를 부르고 크기를 다시 잡으면 캔버스가 지워진다. 건너뛰면 홈으로 돌아올 때 빈 프레임이 보일 수 있어 그대로 뒀다.
