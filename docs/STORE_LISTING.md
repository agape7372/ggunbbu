# 건뿌 — Play 스토어 등록정보 원고

## 앱 이름 (30자 이내)

```
건뿌!! - 떨어지는 건물 베기
```

대안(짧게): `건뿌!!`

## 짧은 설명 (80자 이내)

```
하늘이 건물을 던진다. 자격증 없는 졸라맨이 벤다. 한 손으로 되는 병맛 액션.
```

(38자 — 여유 있음)

## 자세한 설명 (4000자 이내)

```
■ 하늘이 던지면, 베면 된다

멸망해가는 지구. 하늘이 건물을 뽑아 던지기 시작했다.
막을 사람은 자격증 없는 졸라맨 '뿌뿌' 하나뿐이다.

떨어지는 건물을 베고, 부수고, 밟히지 않으면 된다. 그게 전부다.

■ 조작은 넷

점프 · 공격 · 가드 · 필살.
한 손으로도 되게 버튼 네 개만 뒀다. 왼손잡이 배치도 있다.
키보드로도 된다 (↑ 점프 · ↓ 가드 · Z 공격 · X 필살).

■ 부술 것들

· 1막 — 네 구역, 네 가지 건축양식. 서쪽 회랑부터 무너진 신도시까지
· 2막 — 고장난 감시위성 '보름호'. 번개와 화산탄이 같이 온다
· 버터바 챌린지 — 1겹부터 100겹까지. 겹겹이 쌓인 걸 한 번에
· 토코톤 — 끝까지 가는 엔드리스. 기록이 남는다

■ 이런 게임입니다

· 인터넷 없이 됩니다. 비행기에서도, 지하철에서도
· 계정도 로그인도 없습니다. 기록은 폰 안에만 남습니다
· 유료 상품 없습니다. 광고는 원할 때 직접 눌러서 보는 것뿐입니다
· 한 판 3분. 손이 기억할 때까지 반복하는 종류의 게임입니다

■ 만든 이야기

2004년 무렵 국내 프리게임으로 돌던 '건물 부수기' 장르에 바치는 오마주입니다.
그림·소리·문장·코드는 전부 새로 만들었습니다.

브라우저 버전: https://agape7372.github.io/ggunbbu/
```

## 그래픽 자산 체크리스트

| 자산 | 규격 | 상태 |
|---|---|---|
| 앱 아이콘 | 512×512 PNG (알파 없음) | `public/icons/icon-512.png` 확인 후 제출 |
| 피처 그래픽 | 1024×500 PNG/JPG | **미제작** — Wave 3 아트에서 같이 뽑을 것 |
| 폰 스크린샷 | 최소 2장 (16:9 또는 9:16, 320~3840px) | **미촬영** — 타이틀 / 1막 / 2막 보스 / 버터바 4장 권장 |

스크린샷은 `npm run dev` + 모바일 뷰포트 375×812로 찍으면 그대로 세로 비율이 맞는다.

## 데이터 보안(Data Safety) 답변

| 항목 | 답 |
|---|---|
| 데이터를 수집하거나 공유합니까? | **예** — 광고 SDK가 광고 ID를 처리 (아래 참조) |
| 앱이 수집하는 데이터 유형 | 앱 활동 없음 / 개인정보 없음 / 위치 없음 / 연락처 없음 |
| 광고 ID(AAID) | Google AdMob이 보상형 광고 재생 시 사용. 개발자는 수집·저장하지 않음 |
| 데이터 전송 시 암호화 | 예 (HTTPS) |
| 사용자가 데이터 삭제를 요청할 수 있습니까? | 앱 삭제로 전부 삭제됨 (서버 저장분 없음) |
| 게임 진행도 | **기기 내 저장만** — 서버 전송 없음 |
| 개인정보처리방침 URL | `https://gunbbu-ota.vercel.app/privacy.html` (§RELEASE.md 8) |

★AdMob을 켜서 제출하는 이상 "데이터 수집 없음"으로 답하면 안 된다 — 광고 ID 항목을 반드시 체크한다.

## 콘텐츠 등급 설문 답변

- 폭력: **만화적/비현실적** — 건물이 부서지고 졸라맨이 깔린다. 피·상해 묘사 없음
- 성적 콘텐츠: 없음
- 욕설: 없음 (병맛 감탄사만)
- 통제 물질: 없음
- 도박: 없음 (확률형 상품·룰렛 없음)
- 사용자 간 상호작용: 없음 (온라인 기능·채팅·랭킹 서버 없음)
- 위치 공유: 없음
- 개인정보 공유: 없음
- 디지털 구매: **없음** (v1은 IAP 제외 — ROADMAP 판정)
- 광고 포함: **예** (보상형 광고, 사용자가 직접 눌러야 재생)

예상 등급: 전체이용가 / PEGI 3 / ESRB Everyone.
