# 건뿌 — Play 스토어 등록정보 원고

## 앱 이름 (30자 이내)

```
건뿌 - 떨어지는 건물 베기
```

(15자.) 느낌표 반복(`!!`)은 스토어 제목의 특수문자 반복 정책에 걸릴 수 있어 제목에서는 뺐다. 앱 안 로고의 「건뿌!!」는 그대로 둬도 된다. 짧은 대안은 `건뿌`.

## 짧은 설명 (80자 이내)

```
하늘이 건물을 던진다. 자격증 없는 졸라맨이 벤다. 한 손으로 되는 병맛 액션.
```

(44자 · 여유 있음)

## 자세한 설명 (4000자 이내)

```
■ 하늘이 던진다. 베면 된다

멸망해 가는 지구. 하늘이 건물을 뽑아 던지기 시작했다.
막을 사람은 자격증 없는 졸라맨 하나뿐이다.

떨어지는 건물을 베고 튕기고 부순다. 깔리지만 않으면 된다.

■ 조작은 넷

점프 · 공격 · 가드 · 필살. 버튼은 네 개뿐이다.
왼손 조작이 있고 버튼 배치도 바꿀 수 있다.
키보드도 된다 (↑ 점프 · ↓ 가드 · Z 공격 · X 필살).

■ 부술 것들

· 아케이드: 1막 네 구역(서쪽 회랑 · 강턱 시장 · 기와능선 · 철근 해안), 2막은 하늘에서 내려온 철거 집게 「집행기」
· 작업 지시서: 열세 장. 판마다 기한과 전임자 기록이 있다. 견습 · 정규 · 외주 세 난이도. 숨은 특기 사항 도장도 있다
· 구역 작전: 열린 구역을 골라 바로 시작. 2막을 깨면 특별작전 넷이 열리고, 목표를 채우면 B · A · S 도장이 찍힌다
· 야근: 2막을 깨면 열린다. 끝없이 떨어진다. 기록이 남는다
· 버터바 챌린지: 얇은 겹부터 100겹 타워까지

■ 무기와 필살

철거칼 · 오함마 · 빠루 · 그라인더 · 삽 · 비계 파이프 · 전동 드릴 · 곡괭이 · 코어 드릴 · 굴착 드릴 · 착암기 · 다이아 드릴, 그리고 대검 열아홉 자루.
닿는 거리 · 띄우는 힘 · 필살 차는 속도가 저마다 다르다.
철거칼 말고는 건물을 부숴 모은 먼지로 사야 한다.
필살은 여섯 가지. 장착한 하나를 판에서 쓴다.

■ 얼굴은 직접 찍는다

16×16 도트판에 마스크를 그려 졸라맨 머리에 씌운다.
졸라맨 선 색 · 칼빛 · 효과글자도 고를 수 있다.

■ 보급 상자와 안전모

건물을 부수다 보면 상자가 나온다. 믹스커피 · 장갑 · 먼지 자루.
나오는 순서는 늘 같다. 뽑기가 아니다.
안전모는 콤보 50 · 200 · 500에서 하나씩 받는다. 한 번 깔려도 버틴다.

■ 이런 게임입니다

· 인터넷 없이 됩니다. 광고와 결제만 연결이 필요합니다
· 계정도 로그인도 없습니다. 기록은 폰 안에만 남습니다
· 뽑기는 없습니다. 유료 상품은 구성이 정해진 꾸러미뿐이고, 판은 전부 무료로 깹니다
· 광고는 보상을 받으려고 직접 누를 때만 나옵니다
· 한 판은 짧게는 몇 분입니다. 손이 기억할 때까지 다시 하는 게임입니다

■ 만든 이야기

예전에 돌던 「건물 부수기」 프리게임에 바치는 오마주입니다.
그림 · 소리 · 문장 · 코드는 전부 새로 만들었습니다.

브라우저 버전: https://agape7372.github.io/ggunbbu/
```

## 데이터 보안(Data Safety) 답변

기준: Google AdMob 공식 안내 <https://developers.google.com/admob/android/privacy/play-data-disclosure> (2026-10-25 확인, Google Mobile Ads SDK 25.5.0 기준 표). 그 페이지는 **최신 SDK 버전 기준만** 싣는다 — 제출 직전에 다시 열어 비교하고, 앱에 실린 SDK 버전(`shell/node_modules/@capacitor-community/admob/android/build.gradle`의 `play-services-ads`, 기본 25.4.+)이 다르면 항목을 재확인한다.

### 개요

| 질문 | 답 |
|---|---|
| 앱이 사용자 데이터를 수집하거나 공유합니까? | **예** — Google Mobile Ads SDK가 자동으로 수집·공유 (아래 항목별 표) |
| 개발자가 직접 수집하는 데이터 | **없음** — 개발자 서버·계정·로그인·분석 SDK 없음. 게임 기록과 구매 확인 값은 기기 안(localStorage)에만 있고 전송하지 않는다. 결제는 Google Play가 처리한다. 아래 표는 광고 SDK 몫이고, 「진단」에는 결제 라이브러리 몫도 들어간다(아래 11-14 실측) |
| 전송 중 암호화 | **예** — Google 안내: SDK가 수집하는 데이터는 TLS로 전송 중 암호화 |
| 사용자가 데이터 삭제를 요청할 수 있습니까? | **예** — ① 앱 삭제로 기기 저장분 삭제 ② 광고 ID는 기기 설정 → Google → 광고에서 재설정·삭제 ③ 방침의 책임자 이메일로 요청. 개발자 보관분은 없다 |
| 개인정보처리방침 URL | `https://agape7372.github.io/ggunbbu/privacy.html` |

### 항목별 (Play Console 범주 → 데이터 유형)

| 범주 → 유형 | 수집 | 공유 | 필수/선택 | 목적 | Google 안내의 근거 |
|---|---|---|---|---|---|
| 위치 → **대략적 위치** | 예 | 예 | 필수 | 광고 또는 마케팅 · 분석 · 사기 방지·보안·규정 준수 | IP 주소로 기기의 대략적 위치를 추정할 수 있음 |
| 앱 정보 및 성능 → **진단** | 예 | 예 | 필수 | 위와 같음 | 앱·SDK 성능 데이터(실행 시간, 응답 없음 비율, 에너지 사용량) |
| 기기 또는 기타 ID → **기기 또는 기타 ID** | 예 | 예 | 필수 | 위와 같음 | 광고 ID, 앱 세트 ID |
| 앱 활동 → **앱 상호작용** | 예 | 예 | 필수 | 위와 같음 | 앱 실행, 탭, 영상 시청 같은 사용자 상호작용 |

- 목적은 Google 페이지가 항목별이 아니라 SDK 전체에 한 줄로 적어 둔다(「광고, 분석, 사기 방지」). 그래서 네 항목 모두 같은 세 가지를 체크한다.
- 「필수」: 앱 안에 SDK를 끄는 스위치가 없어서다(사용자는 기기의 광고 ID 설정으로만 조정).
- **체크하지 않는 것**: 비정상 종료 로그(Google 표에 없음) · 정확한 위치 · 개인 정보(이름·이메일·연락처 등) · 금융 정보 · 건강 · 메시지 · 사진·동영상 · 오디오 · 파일 · 캘린더 · 연락처 · 앱 내 검색·웹 탐색 기록. 하나라도 체크하려면 근거(실제 수집)가 있어야 한다.
- 「기기 정보」(기종·OS 버전)는 방침 본문에는 적었지만(광고 요청에 따라가는 일반 정보라 넉넉히 공개) Google 표와 콘솔 범주에는 별도 항목이 없어 체크하지 않는다.
- 선택형 기능(고급 보고 등)을 켜면 항목이 늘 수 있다 — 지금 앱은 켜지 않았다.
- **결제 라이브러리도 보낸다(2026-11-14 에뮬레이터 실측)**: Play Billing Library 9.1.0이 앱을 켠 지 60~90초 사이에 `firebaselogging.googleapis.com`으로 한 번 보낸다(보냄 2.5KB). 대기열(`com.google.android.datatransport.events`, transport `PLAY_BILLING_LIBRARY`)에서 읽힌 글자열 = 라이브러리 판 · 앱 패키지 이름 · 기기 제조사 · 기종 · OS 빌드 지문 · 결제 연결 결과 문장. 광고 ID · 계정은 글자열로는 안 보였다(이진 칸은 못 읽음). Play SDK Index의 Play Billing 항목은 Data safety 안내가 「Not provided」다. 그래서 위 표의 「진단」에 넣어 두고 방침 §4 · §5에 적었다. 결제가 되는 실기기에서 같은 전송이 나가는지는 못 봤다(에뮬은 결제 불가라 실패 기록이 나감).
- 광고 SDK는 광고 보기 전에 보내지 않는다(같은 날 실측: 광고 단추 전 앱 UID 통신은 위 결제 라이브러리 한 번뿐 · 광고 준비 뒤 1MB). 매니페스트 `DELAY_APP_MEASUREMENT_INIT`가 이 상태를 고정한다.

### 광고 ID 선언 (앱 콘텐츠 → 광고 ID)

- 앱이 광고 ID를 사용합니까? **예** (AD_ID 권한이 광고 SDK로 합쳐져 매니페스트에 들어간다).
- 목적: **광고 또는 마케팅** (Data Safety의 광고 ID 항목과 같게 맞춘다).
- 「아니오」로 답하면 Android 13+ 기기에서 광고 ID가 0으로 와 광고 품질이 떨어지고, 매니페스트와 어긋나 심사 반려 사유가 된다.
