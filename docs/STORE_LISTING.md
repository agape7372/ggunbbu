# 건뿌 — Play 스토어 등록정보 원고

## 앱 이름 (30자 이내)

```
건뿌 - 떨어지는 건물 베기
```

(15자.) 느낌표 반복(`!!`)은 스토어 제목의 특수문자 반복 정책에 걸릴 수 있어 제목에서는 뺐다. 앱 안 로고의 「건뿌!!」는 그대로 둬도 된다. 짧은 대안은 `건뿌`.

## 짧은 설명 (80자 이내)

```
하늘이 건물을 던진다. 자격증 없는 졸라맨이 벤다. 한 손으로 되는 병맛 액션.
```

(38자 — 여유 있음)

## 자세한 설명 (4000자 이내)

```
■ 하늘이 던지면, 베면 된다

멸망해가는 지구. 하늘이 건물을 뽑아 던지기 시작했다.
막을 사람은 자격증 없는 졸라맨 '뿌뿌' 하나뿐이다.

떨어지는 건물을 베고, 부수고, 밟히지 않으면 된다. 그게 전부다.

■ 조작은 넷

점프 · 공격 · 가드 · 필살.
한 손으로도 되게 버튼 네 개만 뒀다. 왼손잡이 배치도 있다.
키보드로도 된다 (↑ 점프 · ↓ 가드 · Z 공격 · X 필살).

■ 부술 것들

· 1막 — 네 구역, 네 가지 건축양식. 서쪽 회랑부터 무너진 신도시까지
· 2막 — 건물을 집어 던지는 철거 장치 '집행기'. 하늘에서 집게가 내려온다
· 버터바 챌린지 — 1겹부터 100겹까지. 겹겹이 쌓인 걸 한 번에
· 토코톤 — 끝까지 가는 엔드리스. 기록이 남는다

■ 연장은 넷

철거칼 · 오함마 · 빠루 · 그라인더.
오함마는 건물을 더 띄우고, 빠루는 멀리 닿고, 그라인더는 필살이 빨리 찬다.
연장은 건물을 부숴 모은 먼지로 산다.

■ 보급 상자

건물을 몇 채 부수면 상자가 하나씩 나온다.
안전모 · 믹스커피 · 장갑 · 먼지 자루. 나오는 순서는 늘 같다. 뽑기가 아니다.
안전모를 쓰면 한 번 깔려도 버틴다.

■ 이런 게임입니다

· 인터넷 없이 됩니다. 비행기에서도, 지하철에서도
· 계정도 로그인도 없습니다. 기록은 폰 안에만 남습니다
· 유료 상품 없습니다. 광고는 원할 때 직접 눌러서 보는 것뿐입니다
· 한 판 3분. 손이 기억할 때까지 반복하는 종류의 게임입니다

■ 만든 이야기

2004년 무렵 국내 프리게임으로 돌던 '건물 부수기' 장르에 바치는 오마주입니다.
그림·소리·문장·코드는 전부 새로 만들었습니다.

브라우저 버전: https://agape7372.github.io/ggunbbu/
```

## 데이터 보안(Data Safety) 답변

기준: Google AdMob 공식 안내 <https://developers.google.com/admob/android/privacy/play-data-disclosure> (2026-10-25 확인, Google Mobile Ads SDK 25.5.0 기준 표). 그 페이지는 **최신 SDK 버전 기준만** 싣는다 — 제출 직전에 다시 열어 비교하고, 앱에 실린 SDK 버전(`shell/node_modules/@capacitor-community/admob/android/build.gradle`의 `play-services-ads`, 기본 25.4.+)이 다르면 항목을 재확인한다.

### 개요

| 질문 | 답 |
|---|---|
| 앱이 사용자 데이터를 수집하거나 공유합니까? | **예** — Google Mobile Ads SDK가 자동으로 수집·공유 (아래 항목별 표) |
| 개발자가 직접 수집하는 데이터 | **없음** — 개발자 서버·계정·로그인·분석 SDK 없음. 게임 기록은 기기 안(localStorage)에만 있고 전송하지 않는다. 아래 표는 전부 광고 SDK 몫이다 |
| 전송 중 암호화 | **예** — Google 안내: SDK가 수집하는 데이터는 TLS로 전송 중 암호화 |
| 사용자가 데이터 삭제를 요청할 수 있습니까? | **예** — ① 앱 삭제로 기기 저장분 삭제 ② 광고 ID는 기기 설정 → Google → 광고에서 재설정·삭제 ③ 방침의 책임자 이메일로 요청. 개발자 보관분은 없다 |
| 개인정보처리방침 URL | `https://agape7372.github.io/ggunbbu/privacy.html` |

### 항목별 (Play Console 범주 → 데이터 유형)

| 범주 → 유형 | 수집 | 공유 | 필수/선택 | 목적 | Google 안내의 근거 |
|---|---|---|---|---|---|
| 위치 → **대략적 위치** | 예 | 예 | 필수 | 광고 또는 마케팅 · 분석 · 사기 방지·보안·규정 준수 | IP 주소로 기기의 대략적 위치를 추정할 수 있음 |
| 앱 정보 및 성능 → **진단** | 예 | 예 | 필수 | 위와 같음 | 앱·SDK 성능 데이터(실행 시간, 응답 없음 비율, 에너지 사용량) |
| 기기 또는 기타 ID → **기기 또는 기타 ID** | 예 | 예 | 필수 | 위와 같음 | 광고 ID, 앱 세트 ID |
| 앱 활동 → **앱 상호작용** | 예 | 예 | 필수 | 위와 같음 | 앱 실행, 탭, 영상 시청 같은 사용자 상호작용 |

- 목적은 Google 페이지가 항목별이 아니라 SDK 전체에 한 줄로 적어 둔다(「광고, 분석, 사기 방지」). 그래서 네 항목 모두 같은 세 가지를 체크한다.
- 「필수」: 앱 안에 SDK를 끄는 스위치가 없어서다(사용자는 기기의 광고 ID 설정으로만 조정).
- **체크하지 않는 것**: 비정상 종료 로그(Google 표에 없음) · 정확한 위치 · 개인 정보(이름·이메일·연락처 등) · 금융 정보 · 건강 · 메시지 · 사진·동영상 · 오디오 · 파일 · 캘린더 · 연락처 · 앱 내 검색·웹 탐색 기록. 하나라도 체크하려면 근거(실제 수집)가 있어야 한다.
- 「기기 정보」(기종·OS 버전)는 방침 본문에는 적었지만(광고 요청에 따라가는 일반 정보라 넉넉히 공개) Google 표와 콘솔 범주에는 별도 항목이 없어 체크하지 않는다.
- 선택형 기능(고급 보고 등)을 켜면 항목이 늘 수 있다 — 지금 앱은 켜지 않았다.

### 광고 ID 선언 (앱 콘텐츠 → 광고 ID)

- 앱이 광고 ID를 사용합니까? **예** (AD_ID 권한이 광고 SDK로 합쳐져 매니페스트에 들어간다).
- 목적: **광고 또는 마케팅** (Data Safety의 광고 ID 항목과 같게 맞춘다).
- 「아니오」로 답하면 Android 13+ 기기에서 광고 ID가 0으로 와 광고 품질이 떨어지고, 매니페스트와 어긋나 심사 반려 사유가 된다.

## 콘텐츠 등급 설문 답변

- 폭력: **만화적/비현실적** — 건물이 부서지고 졸라맨이 깔린다. 피·상해 묘사 없음
- 성적 콘텐츠: 없음
- 욕설: 없음 (병맛 감탄사만)
- 통제 물질: 없음
- 도박: 없음 (확률형 상품·룰렛 없음)
- 사용자 간 상호작용: 없음 (온라인 기능·채팅·랭킹 서버 없음)
- 위치 공유: 없음
- 개인정보 공유: 없음
- 디지털 구매: **없음** (v1은 IAP 제외 — ROADMAP 판정)
- 광고 포함: **예** (보상형 광고, 사용자가 직접 눌러야 재생. 콘솔 「앱에 광고 포함」도 예)

예상 등급: 전체이용가 / PEGI 3 / ESRB Everyone.

## 앱 카테고리·태그

- 카테고리: 게임 → 액션
- 태그: 아케이드, 캐주얼, 오프라인, 한 손 조작
- 대상 연령(앱 콘텐츠 → 대상 연령): **16~17세, 18세 이상**만 체크한다.
  - 사유: 개인정보처리방침의 「만 14세 미만 아동을 대상으로 하지 않는다」와 같은 선을 유지하고, Families 정책(아동 대상 앱 요건) 적용을 피한다.
  - 이 선택은 콘텐츠 등급(전체이용가 예상)과 별개다. 등급은 폭력·도박 같은 내용으로 정해지고, 대상 연령은 앱이 누구를 겨냥하는지 선언하는 것이다.
  - 졸라맨 만화풍이라 콘솔의 「아동에게 매력적인 앱입니까」 류 질문이 나오면 아동 겨냥이 아니라는 취지로 답하되, 문구는 콘솔 화면에서 다시 확인한다.
